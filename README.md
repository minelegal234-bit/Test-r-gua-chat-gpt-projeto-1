# Régua Flutuante Android

Projeto Android genérico de uma régua sobreposta a outros aplicativos.

Recursos:
- Permissão "Exibir sobre outros apps"
- Serviço em primeiro plano para manter a régua ativa
- Arrastar pela tela
- Girar em passos de 5 graus
- Redimensionar com + e -
- Botão para fechar

Abra o projeto no Android Studio e gere o APK.
